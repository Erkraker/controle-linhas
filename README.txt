# Controle de Linhas V7

Arquitetura limpa:
- index.html = estrutura
- style.css = visual
- app.js = regra do sistema (principal arquivo para futuras atualizações)
- data.js = cadastro inicial
- firebase-config.js = configuração Firebase
- service-worker.js = cache/offline
- manifest.json = PWA

Nas próximas atualizações, normalmente você vai substituir só o arquivo app.js.
